## Expanded version

### Challenge

A large Confluence migration required thousands of repetitive, error-prone changes. Completing the
work manually through the UI would have consumed hundreds of hours and made consistent verification
difficult.

### My contribution

I translated the migration needs into requirements for a family of focused Python utilities. I
designed the command-line workflows, confirmation steps, progress and error feedback, debug modes,
version comments, and documentation; directed AI-assisted coding; reviewed and tested changes in
the working environment; and maintained stable versions in Git as the tools evolved.

### Outcome

Six teammates relied on the original tool family. The automation saved hundreds of hours of manual
work and helped the team complete the migration ahead of schedule.

### Public artifact

Because the original code contained employer-specific implementation details, the linked GitHub
repository is an AI-assisted, sanitized reconstruction of one representative redirect-management
workflow. It demonstrates the API, CLI, safeguards, and documentation patterns without publishing
internal source or data. The reconstruction has offline automated tests but has not been
integration-tested against a live Confluence instance. It is a demonstration artifact, not a
supported production package.

Airbnb did not sponsor, review, or endorse the public reconstruction.
